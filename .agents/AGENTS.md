# AGENTS Guidelines

## Mandatory Pre-coding Workflow
Before starting research or writing any code, ALWAYS read and adhere to the guidelines from the following skills located in `.agents/skills/`:

1. **`taste-skill`** (`.agents/skills/taste-skill/README.md`):
   - Strict Anti-Slop Frontend Framework principles.
   - Enforce unified color systems, harmonious palettes, crisp typography, and modern micro-interactions.
   - Ban mismatched colors, floating uncoordinated badges, or generic placeholder UI elements.

2. **`superpowers`** (`.agents/skills/superpowers/README.md`):
   - Systematic software engineering workflow: clarify specs, review design, write clean DRY code, follow TDD/verification, and maintain robust error handling.
